# 实验：P1 uni-app 平台限制探测

**这是实验原型，不是 P2 正式基础，也不是业务小程序。**

用途：把 uni-app + Vue 3 编译为微信小程序，核对微信端「只跟随系统」时窗口背景、页面样式和底栏的表现。

底栏四个入口：

- 主题：显示当前系统外观，说明不要在应用里强制换肤
- 首页、次页：改系统外观后再切页，看首帧和业务区
- 原生：弹窗和键盘

切换系统外观、切 tab、看闪色由人工完成。助手只保留结构化结论，不代替点选。

清单见 [CHECKLIST.md](CHECKLIST.md)。P1 完成条件不要求真机或 iOS；用户额外在模拟器与真机完成视觉验收并判定通过。iOS 未单独声明。
