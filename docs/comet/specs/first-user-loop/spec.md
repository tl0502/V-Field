# P3 首个完整用户流程

本规格定义 P3 的完整目标行为：域运营配置、成员入域、按文章类型发布、访客阅读、作者删除，以及本次新增的公开用户号与用户互搜。用户于 2026-09-14 明确确认上一 session 的完整 P3 范围，包含 Q1–Q10、输入数值、初始化与交互细则；Q11 已选择固定 8 位随机数字用户号。规格存在不表示业务已经实现或验收通过。

## 目的

在 P2 正式身份骨架上形成一条完整用户流程，保持业务域、平台模板、文章类型、标签、作者和权限的边界。旧代码仅用于核对 UI 和复用线索；旧校验、旧数据及旧测试不替代新版合同。

## Requirements

### Requirement: 首期闭环与域前端

本轮目标流程是：

1. 平台运营者在平台后台查找已有平台账号并指定汽车验证域的域运营者。
2. 域运营者在域后台创建本域文章类型，选用平台模板并设置 Block 使用规则；也可以新增本域标签。
3. 微信登录用户申请入域，由该域运营者批准或拒绝。
4. 成员选择本域可用文章类型，编辑正文/自由描述车源卡片，复用或新建标签，预览并发布。
5. 未登录访客从当前域列表进入详情，读取公开内容。
6. 作者可删除整篇已发布内容，删除后新的列表/详情请求不再返回其内容。

交付一个面向预置汽车验证域 auto-verify 的完整用户体验。页面与请求明确域身份，显示真实域名，内容同时绑定作者和域。共用页面、编辑器和后台，按数据与权限区分业务域；不为未来所有行业分别开发前端。

初始化只提供正文和车源卡片两个平台模板。业务文章类型、标签不预置旧数据或固定六项列表：运营者从页面建立类型，标签由运营者新增或成员随发布创建。没有可用类型时，发布入口明确提示暂不能发布及需要域运营者配置，不伪装成未入域，也不允许绕过类型直接发布。

| 入口 | 必须完成的行为 |
| --- | --- |
| 当前域首页 | 真实域名、公开列表、发布入口，加载/空/失败及继续加载 |
| 登录/我的 | 真实微信登录、公开用户号及复制、用户号找人入口、当前域申请状态与可用操作 |
| 用户号找人 | 已登录用户输入完整公开用户号，读取对应账号的最小公开识别结果；非法输入、无结果及失败反馈 |
| 申请引导 | 未登录引导登录；非成员可申请；待审可取消；拒绝/取消后可重申请 |
| 发布/预览 | 选择文章类型、按规则编辑正文和卡片、选择或新建标签、本地草稿、预览、发布与失败恢复 |
| 内容详情 | 真实作者/域/类型/时间、完整正文/卡片/标签，作者删除 |
| 平台后台 | 按公开用户号查找、指定域运营者、必要时生成并取得管理密码 |
| 域后台 | 管理登录、待审申请、文章类型及 Block 规则、本域标签新增/查看/停用 |

验证跨域授权可以使用隔离测试域；这不等于交付多域切换或建域后台。

### Requirement: 角色与权限

同一账号可兼任多个角色，但每项操作分别检查真实授予。

| 身份 | 能力 | 不隐含的权限 |
| --- | --- | --- |
| 访客 | 读取公开列表和详情 | 申请、发布、标签新建、管理和删除 |
| 平台账号 | 按公开用户号找人、申请入域、读取本人申请、取消本人待审申请 | 找人不授予管理信息读取权；登录不能直接发布 |
| 有效域成员 | 在该域发布，复用或创建本域文章标签 | 审批、配置类型、停用标签或删除他人内容 |
| 域运营者 | 本域审批、类型配置、标签新增/查看/停用 | 其他域管理、平台账号管理信息查询；不自动取得成员发布权 |
| 平台运营者 | 查找目标平台账号、授予目标域运营者资格 | 不自动拥有各域审批、发布或作者删除权 |
| 内容作者 | 删除本人已发布内容 | 更新已发布内容、删除他人内容 |

服务端校验会话账号、域、类型、标签和内容归属，不能信任客户端传入作者。禁用账号、无效会话和无效域不得完成受保护写操作。作者删除校验作者身份，不以仍为域成员为额外前提。

申请状态、成员角色和管理权限以服务端当前结果为准；小程序进入/返回相关页面或刷新时读取最新结果，不要求本轮增加消息推送。

### Requirement: 平台模板、域文章类型与使用规则

平台模板定义类型、版本、输入字段、编辑/阅读组件和可配置边界。域运营者维护本域文章类型及模板使用规则，成员在文章中填写实例内容。

本轮内置：

| 模板 | 内容字段 | 域可配置部分 |
| --- | --- | --- |
| 正文 | 文字/数字与换行 | 是否可用、是否必填 |
| 车源卡片 | 自由描述文字/数字与换行 | 是否可用、最少及最多张数 |

正文必填指所有正文段合计含非空文本，不按 textarea 或分段数量判断。卡片数量按实际卡片实例计算。平台支持纯正文；特定类型可以要求卡片，不能把某域规则硬编码成平台全局条件。

域后台必须支持：

- 创建、编辑本域文章类型的名称、启用状态和上述规则；类型 ID 稳定，不用名称充当归属 ID。
- 类型名称按输入边界表校验，并在本域按规范化名称去重。
- 新建表单默认正文可用且必填，车源可用、最少 0、最多 50；这是可修改的表单默认值，不自动创建业务类型。
- 车源启用时，最少为 0–50 的整数，最多为 1–50 的整数，最少不得超过最多；禁用时最少/最多均为 0。
- 正文禁用时不能同时必填，且车源必须启用并至少要求 1 张；不能保存两种模板都禁用的配置。
- 停用类型阻止新的发布，保留类型记录及已发布文章；本轮不提供类型删除产品。

所有编辑器入口和发布校验读取同一规则。规则改动生成新版本；并发编辑不能静默覆盖较新的配置。成员直接调用接口也不能绕过必填、数量或域归属。

已发布文章保存发布时的类型名称、规则和模板版本信息，后续类型改名、规则变更或停用不改写历史显示，也不隐藏历史文章。版本/快照的物理存法由实现决定。

已有草稿遇到新规则或类型停用时保留原内容并指出不符合项，不能自动删卡或换成别的类型后发布。修改后再次提交使用最新规则；发布事务与规则变更须形成明确先后结果。

平台模板编写/发布后台、自定义字段、任意脚本、条件表达式和版式搭建器后置。真实域配置页面及发布校验必须交付，不能用手工写库或固定规则代替。

### Requirement: 输入限制与协议边界

这些值是随本次完整 Shape 确认提交的设计值，不能声称来自已批准的旧规则。

| 字段 | 合法范围与结果 |
| --- | --- |
| 文章类型名称 | 1–32 字符，单行，去首尾空白后非空，本域规范化同名唯一 |
| 文章标题 | 必填，1–80 字符，单行，去首尾空白后非空 |
| 正文总长度 | 最多 20,000 字符，所有正文段合计，换行计入；是否必须非空取决于类型 |
| 单张车源描述 | 必填，1–2,000 字符，去首尾空白后有内容，原有换行保留 |
| 车源卡片数量 | 0–50，并满足当前类型的最少/最多规则 |
| 单个标签名称 | 1–24 字符，单行，规范化后非空 |
| 单篇标签数量 | 0–6 个不同标签，重复选用按同一标签处理 |
| 发布请求体 | 最多 1 MiB；超出返回明确参数错误，不写入部分内容 |
| 既有身份请求体 | 保留 P2 的 64 KiB 上限，不因新增发布而一起放宽 |

字符长度按 Unicode 代码点计数，界面计数和服务端一致。正文/描述换行统一为 LF 并保留语义，不因卡片插入或删除丢失文字。标题、类型名和标签不能包含换行或控制字符。

类型名与标签同名判断：去首尾空白、连续空白合并、英文字母不区分大小写；已存在记录的显示名称不被后来大小写不同的输入覆盖。文章标题和正文不做大小写改写。

合法内容不得被另一层更小的网络限制静默拒绝；必须验证最大合法文章经实际小程序传输进入发布接口并完整读回。当前 API 的 64 KiB 是已知需适配的代码约束，不是 P3 已能承载最大文章的证据。

### Requirement: 公开用户号与用户检索

平台账号保留内部 UUID 主键 account.id，并增加独立、全平台唯一的公开 userid。内部身份、域角色、会话、作者归属和外键继续关联 UUID；不截短 UUID 充当用户号，不把公开号码当作密码或授权依据。

用户已选择自动分配固定 8 位随机数字，全平台唯一且不可修改。号码范围为 10000000–99999999，首位非零，不直接体现注册顺序；采用安全随机来源并在碰撞时重新生成。号码以字符串在接口和前端传递，用户不能选择或修改号码。

所有创建账号的路径必须分配用户号，包括微信首次登录与平台运营者初始化。保留的既有账号通过增量迁移补号，原 UUID、微信绑定、凭证和角色关系继续有效；重登及重复迁移不换号。唯一性由数据库约束保障，并发和碰撞不能产生重复号码、重复账号或不完整身份。账号禁用后原号码仍归属该账号。

| 使用位置 | 行为与返回边界 |
| --- | --- |
| 本人身份与“我的” | 展示并可复制完整用户号，界面明确称为“用户号”；公开号码与内部 UUID 不混用 |
| 用户端找人 | 从“我的”进入最小检索页，已登录用户按完整号码精确查找全平台有效账号；返回该账号的公开用户号，不返回 UUID、微信身份、管理登录名、管理凭证、角色或其他私有字段 |
| 平台后台 | 平台运营者按同一号码精确查询管理目标，可核对账号状态和执行当前范围内的指定操作；内部关联仍使用 UUID |
| 域后台 | 登录使用同一用户号和该账号的管理密码；审批列表以用户号识别申请者，权限仍由真实域角色决定 |
| 文章作者 | 对外展示作者的公开用户号，详情公开返回不以 UUID 作为作者识别信息 |

检索去首尾空白，按最终确认的号码格式验证；不做部分匹配、昵称/手机号查找、注册顺序列表或账号批量枚举接口。用户端不存在或已禁用账号均显示未找到可用用户；请求失败与无结果分别反馈，失败不能显示为查无此人。未登录用户需要先登录，服务端也检查对应会话，查询具有与现有服务一致的频率保护。

查询结果只承担互相核对用户号的最小目的，本轮没有昵称/头像可用于展示，不虚构资料、不扩为完整他人主页或添加好友、关注、消息产品。平台后台需要的状态与管理信息保持管理权限；普通用户可找人不代表可以访问管理查询。

### Requirement: 指定运营者与管理登录

平台后台在已有平台账号中按公开 userid 精确查找。结果显示完整用户号与账号状态，明确目标域后授予资格。小程序“我的”显示并可复制同一用户号。不存在、禁用账号或无效域不得被授予。

管理账号仍是同一平台账号：

| 目标情况 | 处理 |
| --- | --- |
| 无管理凭证 | 为本次指定生成安全随机管理密码，页面可复制；成功后用公开用户号和该密码登录域后台 |
| 已有管理凭证 | 沿用已有密码，不覆盖、不读取或回显原密码；公开用户号仍可登录域后台 |
| 已有同域运营者资格 | 返回已具备资格，不重复授予或重新生成密码 |
| 权限不足/目标无效 | 明确失败，资格与凭证均不写入 |

新密码应在最终指定请求前已可由当前页面取得，提交失败/重试保留本次值；只有本次凭证实际建立成功才提示该密码有效。出现并发建立凭证时重新核对，不误把未生效的临时密码当成登录凭证。凭证和资格写入保持一致，同次操作重试不覆盖既有密码。

只保存密码哈希，不把生成的明文写入日志或持久浏览器存储；本次页面可展示用于现场交付，不自动向其他人发送消息。关闭本次结果后不提供原密码回查。本轮不扩为密码找回、重置或强制改密产品。

域管理支持公开用户号解析到同一账号管理凭证，已有平台后台登录方式及 Cookie/受众隔离保留。公开号码与已有管理登录名应采用明确的解析规则，不能因名字碰撞将密码校验导向另一账号。登录成功不自动获得没有授予的域权限。

### Requirement: 入域申请与审批

| 当前状态 | 申请者动作 | 域运营者动作 |
| --- | --- | --- |
| 未申请 | 新建待审申请 | 无记录可处理 |
| 待审 | 看见待审，不能重复新建；可取消本人申请 | 批准并授予有效成员，或拒绝 |
| 已拒绝 | 可以创建新的待审申请 | 旧记录不能再审批 |
| 已取消 | 可以创建新的待审申请 | 旧记录不能再审批 |
| 已批准/有效成员 | 显示已入域和发布入口，不重复申请 | 不重复授予成员 |

旧拒绝/取消记录保留，不改回待审冒充新申请。“我的”和发布前引导能显示最新状态；审批列表仅返回有权处理的本域待审记录。

取消和批准/拒绝只允许一次从待审转换。竞争请求只有一个结果生效，后到请求读取真实最新状态；批准与成员资格写入原子完成，不能出现已取消却新增成员或已批准但无成员资格。

P2 仅有 pending/approved/rejected，本轮增加可追踪的取消状态及相应数据约束。空列表、请求失败和操作失败均有反馈，不能仅禁用前端按钮代替服务端约束。

### Requirement: Block 与内容合同

文章拥有作者、域、类型、标题、标签及有序 Block 内容。平台模板定义和文章实例分开，卡片实例只属于本篇文章，不跨文章共享修改，也没有独立的发布权限。

- 正文是普通文字/数字与换行；车源卡片为自由描述，不改成车型/价格/里程固定字段表单。
- 每个 Block 有稳定实例标识、支持的类型/版本与合法字段。正文段之间可穿插多张卡片；相邻正文段可合并，换行和文字不变。
- 编辑时的空输入占位不当作实际内容保存；零长度段可移除，但有意义的空行不能被重排或吞掉。
- 文章至少含非空正文或一张非空描述卡片，同时满足所选类型规则。只填标题不能发布。
- 只支持本轮两个模板，无图片/音视频/外部图片嵌入或用户 HTML 渲染。文字中的 URL 仍为文本，不变成绕过媒体边界的嵌入。
- 未知类型/版本、重复实例 ID、缺失必填字段、非法值和超限提交被拒绝；不能静默丢弃某个 Block 后当作完整文章成功。
- 正文、卡片、元数据及新建标签属于同一次发布结果，失败回滚，不产生半篇文章或孤立成员标签。

旧 Delta 名称不要求沿用其存法或引入 Markdown/富文本。旧“必须有车源、至少一条有效车源、开发令牌”校验不得作为新版全局条件。

### Requirement: 编辑器与草稿

发布入口先确认真实账号及目标域成员资格，再选择可用文章类型。无类型或全停用时说明暂不能发布，不能错误要求已入域成员重新申请。

主要交互：

1. 输入标题和正文，在当前正文光标处插入车源卡片，文本的前后顺序保留；无有效正文光标时插在文末。
2. 草稿中的卡片可编辑、保存、移除；移除不丢周围文字。拖动卡片在卡片位置间换位，正文段顺序不变。
3. 从本域已有标签中选择；输入不存在的新词时可加入草稿，在成功发布时创建到共享词库。未成功发布的临时词不因键入就成为全域标签。
4. 每个账号 × 域保留一份本地草稿，包含类型/规则版本、标题、文字/卡片顺序和标签。离开后可恢复；不迁入旧全局草稿，不增加云同步。
5. 切换账号不能读取他人草稿；本次响应不能覆盖后来编辑或另一账号/域的内容。存储失败有反馈，不伪称已保存。
6. 清空草稿有明确确认，取消则保留。预览与详情采用一致的渲染规则，返回编辑不改变内容。
7. 切换类型或规则改变时，保留原草稿并提示不符合项，等待作者修改；不能静默删正文、卡片或标签。
8. 确认发布显示实际域和类型；提交中合并重复操作。失败保留草稿并给出可重试结果，成功后清理对应草稿并进入真实详情。

同次提交使用稳定操作标识，成功后的网络重试返回同一篇文章；不能因为重复点击、超时或规则刷新产生多篇。用户改变提交内容应作为新的提交意图处理，不把旧成功响应覆盖到新草稿。

本轮不提供重新打开已发布文章覆盖编辑的路径。卡片已发布后单独移除、改描述、改状态或改标签都属于更新，不能绕过该限制。

### Requirement: 内容发布与作者删除

发布服务端重新检查当前会话、域成员、所选域类型、模板规则和标签可用性，绑定实际作者。类型或标签在编辑期间改变时，返回需核对的信息并保留草稿；文章写入与规则/标签校验形成同一确定结果。

作者可在本人详情删除整篇已发布内容：

- 确认前不删除，取消保留。
- 失败明确反馈并允许重试，不能只移除本地卡片就声称成功。
- 成功后本人本地列表同步移除；新的公开列表/详情请求不再返回正文、卡片或标签内容，旧详情链接显示不可用并可返回列表。
- 非作者即使直接调用接口也不能删除；重复删除不能影响其他文章。
- 本轮无作者更新、管理员内容处置、独立下架/恢复、回收站或重新发布产品。

内部物理删除或保留删除记录由实现选择，公开不可读和作者权限是必须满足的行为。

### Requirement: 阅读与文章展示

| 摘要 | 来自真实正文/卡片文本，不能显示技术标记或把丢失的卡片当作空文章；不承诺推荐算法 |

访客无需登录即可读取已发布且未删除内容。草稿、微信身份、管理凭证和仅本人字段不进入公开返回。

文章/卡片没有自动到期，也不按有效/暂停/已售过滤。类型改名、规则变化、类型停用和标签停用不重新裁剪或隐藏历史文章；作者删除才按本轮删除流程结束公开。已有页面不要求实时推送刷新，但新的读取必须符合最新删除状态。

### Requirement: 标签选择与展示

标签库归属业务域，成员新词供同域成员复用；不同域不因同名共享管理权。本轮不预置固定六项词表。

成员在发布前可选择已有启用标签，或输入符合边界的新词。新词在发布成功时进入共享库，与文章一起保存；运营者则可以在域后台单独新增标签。标签可不选，最多 6 个，重复选用不重复显示。

同域规范化同名标签只有一条，包括并发创建；命中已有启用标签时复用其 ID 与已存显示名称，不能覆盖名称或创建者。同名记录已停用时，不能通过再次新建绕过停用。

域运营者可查看本域标签的名称、创建来源和启用/停用状态，新增或停用标签；不能修改其他域标签。停用只限制之后的使用，历史文章保留发布时的标签名称和可读性。旧草稿含停用标签时提示作者移除或改选，发布不能自动删词后成功。

本轮不提供标签改名、同义词合并/别名、批量替换或硬删除；文章作者不能修改已发布标签。标签新增/停用不变成绕过已发布内容更新限制的入口。

编辑时查找匹配标签是选择辅助；公开标签聚合页、按标签检索文章及筛选结果后置。
